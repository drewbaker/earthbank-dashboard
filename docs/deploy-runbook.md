# Deploy runbook

How to stand up `dashboard.theearthbank.org` on Render, and what to set up outside Render. Later phases add steps here as they need them.

## 1. Google OAuth client (sign-in, and Gmail in phase 5)

In the Google Cloud console, use a project that belongs to the Earth Bank Workspace organization:

1. **APIs & Services → OAuth consent screen**: user type **Internal**. Only accounts in the Workspace can use it, and Google doesn't need to verify the app, even for Gmail's restricted read scope.
2. **APIs & Services → Library**: enable the **Gmail API** (needed in phase 5).
3. **APIs & Services → Credentials → Create credentials → OAuth client ID**, type **Web application**. Add these redirect URIs:
    - `https://dashboard.theearthbank.org/auth/google/callback`
    - `http://localhost:3000/auth/google/callback` (local development)
4. Copy the client ID and secret into Render (`GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`) and into your local `.env`.

## 2. Render service

1. **New → Blueprint**, pointing at this repo. `render.yaml` creates the `earthbank-dashboard` web service with a 10 GB disk at `/var/data`.
2. Fill in the `sync: false` secrets when prompted. `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` are required now. `RESEND_API_KEY` is required before anyone is assigned a task (production refuses to print emails to the console). The others can wait for their phase.
3. `APP_ENCRYPTION_KEY` and `SIDEQUEST_DASHBOARD_PASSWORD` are generated by Render. Don't change `APP_ENCRYPTION_KEY` once Gmail is connected; stored tokens can't be decrypted with a new key.
4. Deploy. Migrations run on start (`prisma migrate deploy`), because the disk isn't mounted during the build.

## 3. Domain

1. Render → the service → **Settings → Custom Domains**: add `dashboard.theearthbank.org`.
2. At the DNS provider for `theearthbank.org`, add the CNAME Render shows (`dashboard` → `earthbank-dashboard.onrender.com`).
3. Wait for Render to issue the certificate. Requests to the `onrender.com` hostname redirect to the custom domain, except `/healthz`.
4. **Settings → Edge Caching**: "All files". Only content-hashed `/_nuxt/` assets are marked public; everything else is `private, no-store`.

## 4. First sign-in

Drew, Leslie and Steve each open `https://dashboard.theearthbank.org` and choose **Sign in with Google**. Their accounts are created on that first sign-in. Anyone else in the Workspace can sign in the same way; to remove someone, remove them in Google Workspace and deactivate them in **Settings → Team**.

## 5. Smoke test

- Sign in with a personal Gmail account: it must be refused with "Use your @theearthbank.org Google account."
- `https://dashboard.theearthbank.org/healthz` returns `{"ok":true}`.
- `/admin/jobs` (signed in) shows the Sidequest dashboard.

## Operations

- **Backups**: nightly `VACUUM INTO` snapshots of `app.db` and `jobs.db` in `/var/data/backups`, 7 kept. To restore, stop the service, copy a snapshot over `/var/data/db/app.db` from the Render shell, and restart.
- **Logs**: Render → Logs. Server lines are prefixed by area (`[api]`, `[jobs]`, `[auth]`, `[backup]`).
